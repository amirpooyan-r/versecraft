# 0002 - Bible Text Policy

## Status
Accepted

## Context
VerseCraft v1.0 must ship with license-safe, offline text sources.

## Decision
Version 1.0 includes only public domain translations bundled with the app:
KJV, WEB, BSB, and POV.

## Consequences
No licensed translations are bundled for v1.0, and users cannot import texts.
