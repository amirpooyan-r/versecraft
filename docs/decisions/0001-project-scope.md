# 0001 - Project Scope

## Status
Accepted

## Context
VerseCraft is intended to generate shareable verse images, not to be a
full Bible reading or study app.

## Decision
VerseCraft is an open-source tool focused on generating shareable verse images.
Version 1.0 is offline-only, with no accounts, analytics, APIs, downloads, or
imports. Verse selection is limited to Book -> Chapter -> Verse range, and
search is out of scope for v1.0.

## Consequences
The UI and data model stay editor-first, and storage is bundled with the app.
